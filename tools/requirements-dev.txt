# Optional dependencies for tools/dev_probe.py only - the game itself
# (requirements.txt at repo root) does not need any of this.
#
# Pillow unlocks two checks dev_probe.py otherwise skips gracefully:
#   - blank/solid-color screenshot detection (catches a broken render even
#     when game state looks perfectly healthy)
#   - a timelapse.gif stitched from all captured screenshots
#
# OpenCV enables advanced visual analysis:
#   - UI element detection (HP bars, status icons, damage numbers)
#   - Change detection between frames (delta encoding)
#   - Visual clustering of similar frames (redundancy reduction)
#   - Color-based event detection (flash effects, screen shake indicators)
#   - Motion detection via optical flow
#   - Entity tracking across frames
#
# scikit-image provides production-grade SSIM and structural analysis
#
# imagehash offers production-grade perceptual hashing (aHash, pHash, dHash)
#   as a fallback/enhancement to our custom OpenCV implementation
#
# Install with:
#   .venv/Scripts/python.exe -m pip install -r tools/requirements-dev.txt
