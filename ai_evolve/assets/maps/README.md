# Карты AI-EVOLVE

## arena_map.json
Процедурно сгенерированная карта арены.

### Структура:
- **terrain**: 2D массив тайлов (biome types)
- **spawns**: точки появления сущностей
- **points_of_interest**: локации (костры, святилища, пещеры, арены)

### Биомы:
- water (непроходимый)
- sand, grass, forest, stone, snow (проходимые с разными модификаторами)

## Создание своей карты
1. Запустите генератор: `python maps/generate_map.py`
2. Отредактируйте JSON вручную или в Tiled
3. Или создайте карту в Blender/Tiled и экспортируйте в JSON
