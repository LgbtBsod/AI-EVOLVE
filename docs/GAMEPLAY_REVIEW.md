# Разбор геймплея (сентябрь 2026)

Игра прогнана инструментами агента, а не на глаз: `agent_play` (управление игрока: спавн врага /
ловушки / сундука, атака, взаимодействие), `qa.py sweep` (Monte Carlo по seed), `dev_probe` со
скриншотами, `probe_db stats`. Все цифры ниже воспроизводятся командами из последнего раздела.

## Коротко

Каркас хороший: игра грузится, детерминирована, работает без окна, у героя есть ИИ, у мира
растёт давление врагов. **Самой игры пока нет**: без действий игрока ничего не происходит, а
когда игрок спавнит врагов, герой не может проиграть. Системы, в которые вложено больше всего
сил (предметы и эффекты: Effect Schema, Lost My Self, тренировочная комната), в игровой цикл не
подключены.

## Что видно в цифрах

| Сценарий | Результат |
|---|---|
| 2–5 минут без действий игрока (`wait 300`, 8 сидов) | в среднем 0,25 убийства; в 6 из 8 прогонов боя нет вообще. Враги появляются в ~160u от героя и не подходят ближе 41u |
| Герой без врагов (`wait 180; story`) | 3 минуты мечется `seeking_hint ↔ seeking_exit` (6 переключений), до выхода не доходит |
| Рой из 10 врагов рядом (`spawn enemy x10; wait 60`, 16 сидов) | **0 смертей из 16**; все 10 врагов убиты; через минуту HP героя всегда полный |
| Обмен ударами в рое | враги: 149 атак по ~2 урона (макс. 7); герой: 29 атак по ~42 (макс. 285) против врагов с 50 HP |
| HP в бою | падает до 44/120, затем повышение уровня мгновенно восстанавливает HP до полного — посреди боя (`src/entities/character.py`, level up: `health = max_health`) |
| Сундук | работает: +50 XP за лут. Ловушка рядом с героем за 20 с не нанесла урона |

## Как это выглядит

Плоское зелёное поле, герой и враги — одинаково красные воксельные фигуры (героя отличает только
подпись «HERO #1»), сундуки и ловушки — цветные кубы. HUD читается (HP / MP / Stamina / Level / XP),
подсказка «1/2/3: spawn enemy/trap/chest» внизу понятна. После первой стычки кадры с 22-й по 60-ю
секунду одинаковые: герой стоит один.

## Нравится ли мне

Как проект — да: идея «игрок — режиссёр уровня, герой учится сам» необычная, а инструменты
вокруг игры сильные (детерминизм, бой за миллисекунды, спеки предметов, исполняемые в Lua и
Python). Как игра сейчас — нет: у режиссёра нет цели и цены решений, у героя нет риска, у мира нет
событий без вмешательства. Играть в это 5 минут скучно, 1 минута — любопытно.

## Что сделать первым (по отдаче)

1. **Враги должны дойти до героя.** Спавн ближе (или дальность обнаружения больше) — цель: первый
   бой в первые 10 с без действий игрока (`agent_play "wait 30"` → `NO_COMBAT` не срабатывает).
2. **Баланс «можно проиграть».** Цель для `sweep "spawn enemy x10; wait 60"`: 20–40% смертей, а не 0.
   Рычаги: урон врагов (сейчас ~2), разброс урона героя (42 в среднем, 285 максимум), лечение при
   повышении уровня (сейчас полное и мгновенное).
3. **Цель для режиссёра.** Бюджет на спавны, очки за «выжил на грани» или за обучение героя — иначе
   нажимать 1/2/3 незачем.
4. **Подключить предметы.** Сундук даёт предмет из каталога (`tools/effect_schema/catalog.py`),
   эффекты идут через тот же рантайм, что проверен кузницей и itemcheck. Lost My Self в настоящем
   бою — лучшая демонстрация того, что уже сделано.
5. **ИИ героя без врагов.** Разобраться с `seeking_hint ↔ seeking_exit`: герой должен доходить до
   выхода и переходить на следующий уровень карты.
6. **Читаемость.** Разные цвета/силуэты у героя и врагов, заметная реакция на удар.

## Как повторить

```bash
python tools/agent_play.py "wait 180; story 20"
python tools/qa.py sweep "spawn enemy x10; wait 60" --seeds 16
python tools/qa.py sweep "wait 300" --seeds 8
python tools/agent_play.py "spawn enemy x10; wait 60" && python tools/probe_db.py stats
python tools/agent_play.py "spawn chest; observe; interact 3; observe"
xvfb-run -a python tools/dev_probe.py --headless --fast --seed 3 --duration 60 --screenshot-interval 10 --action-at 1:1
```
